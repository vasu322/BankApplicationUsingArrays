# Bank Application

A simple Java-based banking application that demonstrates basic banking operations such as customer and account management using object-oriented principles.

## Features
- Hardcoded customer and account data
- Account creation and balance tracking
- Deposit, withdrawal, and transaction history
- Custom exception handling
- Clean package structure following MVC principles

## Project Structure
This project includes the following packages:

- `com.bank.controller` – Handles user interactions and request flow
- `com.bank.dao` – Simulates data access using in-memory lists and hardcoded data
- `com.bank.exceptions` – Contains custom exception classes
- `com.bank.model` – Defines data models like Account, Customer, and Transaction
- `com.bank.services` – Contains service interfaces and business logic
- `com.bank.util` – Utility classes for managing hardcoded data

## Technologies Used
- Java (Core Java)
- Exception handling
- Object-Oriented Programming
- MVC Design Pattern (without real DB or UI)

## How to Run
1. Clone or download the project.
2. Open it in any Java IDE (like Eclipse, IntelliJ, or NetBeans).
3. Compile and run the main controller or service class to test the flow.
4. Since the data is hardcoded, no additional setup (like database) is required.
